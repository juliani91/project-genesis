# Architecture Decision Records

Architecture Decision Records (ADRs) capture the reasoning behind important architectural decisions made during the development of Project Genesis.

Unlike specifications, ADRs explain *why* a decision was made, the alternatives that were considered, and the consequences of adopting that decision.

An ADR is immutable once accepted. If a decision changes in the future, a new ADR should supersede the previous one rather than rewriting history.

## Format

Each ADR contains:

- Status
- Context
- Decision
- Consequences
